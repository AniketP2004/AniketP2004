## Projects Built

### 🛡️ Honeypot IDS: ML-powered intrusion detection
Classifies honeypot traffic into `automated_scan`, `brute_force`, `web_recon`, and `normal`.
- GradientBoosting, RandomForest, and XGBoost models. Best: **F1 = 0.9979**
- 2,369 samples merged from public datasets plus synthetic data
- Found and fixed data leakage, encoder, and model-versioning bugs
- Auto-retrain watchdog, FastAPI + PostgreSQL backend, live dashboard
- **Role:** ML Engineer (team project)
- **Live:** https://honeypot-ml-model-6.onrender.com/

### 🤖 RAG Coding Assistant
Coding assistant powered by a **QLoRA fine-tuned Qwen2.5-Coder-3B** with retrieval and document collections.
- Fine-tuned on Google Colab (T4), exported as ~2 GB Q4_K_M GGUF, served with Ollama
- ChromaDB retrieval with `all-MiniLM-L6-v2`, PDF upload and chunking
- **80% real-knowledge accuracy** on a 50-question structured eval

### 🧮 12 ML Algorithms From Scratch
Twelve classical machine learning algorithms implemented from first principles to understand the math and trade-offs behind each one.

### 📊 Flight Price Predictor
Random Forest regression, **R² = 0.985**.
